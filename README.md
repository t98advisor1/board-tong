# Board-Tong — 스마트 판서 보드

교실 전자칠판·갤럭시탭·아이패드·PC에서 설치 없이 바로 여는 전체화면 수업용 스마트 판서 웹앱입니다.

- **메인 실행 주소 (GitHub 우선)**: https://t98advisor1.github.io/board-tong/
- **간편 직접 접속 주소 (Vercel)**: https://boardtong.vercel.app/ (또는 https://smart-tong.vercel.app/)
- **사용설명서**: https://t98advisor1.github.io/board-tong/smart-board-guide.html

## 주요 기능
- **문서·슬라이드 판서**: PDF 쪽별 고화질 렌더링, PPTX 클릭 애니메이션 단계별 진행, 이미지·유튜브·웹 화면 위 실시간 판서
- **삼성노트 감성 필기 도구**: 만년필·볼펜·연필(흑연 질감)·붓펜(`2pt` 기본), 형광펜(`6pt` 기본), 0.5초 꾸욱 도형·직선 자동 보정
- **3초 다중 레이저 & 자동 번호 스탬프**: 획이 서로 이어지지 않는 3초 다중 레이저(`D`), 밑줄·원 좌측 상단 번호 스탬프 자동 표시(`A`), 슬라이드 변경 시 1번 자동 초기화 및 `SS`/`QQ`/`0` 즉시 초기화
- **편리한 단축키**: `Z` / `X`(및 `,` / `.`, `Esc`) 뒤로 취소·앞으로 다시 실행, `←` / `→` 페이지 넘김, `Ctrl+1` 풀사이즈 확대·터치 이동, `Ctrl+\`` 스닙페이스트 조각 고정
- **내보내기 & 보관함**: 전체화면 로컬 폴더 노트함(IndexedDB), 현재 쪽 PNG 저장, 전체 쪽 PNG 압축(ZIP) 및 합본 PDF 저장·공유
